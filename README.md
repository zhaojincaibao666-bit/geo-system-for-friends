# 星图 GEO

星图 GEO 是本地运行的 AI 可见性监测与内容运营工作台。新安装会载入随项目提供的 60 道监测问题，并从空白运行记录开始。

## 快速启动

1. 安装 Node.js 20 或更新版本，以及 pnpm。
2. 在项目目录运行 `pnpm install`。
3. 复制 `.env.example` 为 `.env`，填写本机的 `AGENT_TOKEN`。
4. 运行 `pnpm start`，然后打开 `http://127.0.0.1:4318`。
5. 在“系统设置”里填写要监测的目标名称和别名。
6. 首次运行网页端监测前，在本机登录对应的 AI 平台。

本地运行记录写入 `data/store.json`，其中可能包含提示词、回答和来源信息。该文件被 Git 忽略，不应提交或分享。题库问题单独保存在 `data/question-bank.json`。

## 题库与监测对象

题库保存“原有题库”和“新增业务题库”各 30 道问题，以及意图、权重和题组信息。监测对象在“系统设置”中配置；系统使用其名称、全称和别名计算提及率与推荐结果。题库不会自动替朋友选择要监测的对象。

## 安全配置

`.env`、平台登录状态、浏览器配置、运行结果、临时文件和调试记录都只保存在本机。不要提交这些文件。平台发布功能需要使用者自行设置 `GEO_PUBLISH_COMPANY_NAME` 和 `GEO_PUBLISH_ACCOUNT`，并完成对应平台登录。

## 常用命令

- `pnpm start`：启动本地系统。

详见 `.env.example` 中的本机设置项。
